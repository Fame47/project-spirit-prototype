FIGHTING SPIRIT - HUNTER ANIMATION PATCH

Built on the current boomerang-return script.

- Boomerang throw animation: side grab -> forward hold -> release
- Boomerang projectile now spawns on the release frame
- Normal and red boomerang both use the same throw animation
- Existing outbound-harmless / 1.5 sec / active-return-hit behavior is preserved
- Dedicated crouch punch sprite
- Dedicated crouch kick/sweep sprite
- Existing spear throw, jump kick, combos, controller support, and projectile behavior are preserved

Install:

2. Allow folders to merge.
3. Replace script.js when prompted.

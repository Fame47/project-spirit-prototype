PROJECT SPIRIT v1.1 — PAUSE MENU / CLEAN SCREEN PATCH

WHAT THIS PATCH DOES
- Clears the always-visible move cards, control strip, and move-note clutter from the fight screen.
- ESC pauses/resumes the match.
- Xbox Menu/Start also pauses/resumes.
- Pause menu has CONTROLLER and MOVESET tabs.
- MOVESET automatically changes to HUNTER or BRUISER based on the chosen fighter.
- The pause layer freezes requestAnimationFrame game updates, interval timers, and timeout-driven transitions while paused.
- Resume and Restart Match are available inside the pause menu.

INSTALL
This is a drop-in index.html patch for the existing Project Spirit v1.0 Hunter Jump Kick + Spear build.
1. Open your v1.0 project folder.
2. Replace the root index.html with the index.html in this patch.
3. Leave the existing style.css, script.js, and assets folder exactly where they are.

No gameplay assets are replaced by this patch. Hunter's current jump kick, spear art, red spear glow, combos, and Xbox gameplay controls remain in the existing v1.0 files.
